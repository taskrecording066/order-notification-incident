# GitHub Project Board

The incident board is organized around the investigation workflow:

- Incident Reported
- Investigation
- Root Cause Analysis
- Validation
- Resolution
- Closed

## Board mapping

- `#1` Order confirmation emails missing for 10-20% of customers -> Incident Reported
- `#2` Event publishing investigation -> Investigation
- `#3` Notification service investigation -> Investigation
- `#4` Deployment review -> Root Cause Analysis

## Repository view

The board should be used to track the issue lifecycle from triage through diagnosis and validation.
